# JanhitWorks - Initiatives Page

Professional React + Vite frontend created from the supplied Janhit Lokshahi Party publication.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes
- The page is responsive and uses reusable, data-driven initiative cards.
- `src/data.js` contains the initiative content.
- `src/assets/` contains selected/cropped visuals from the supplied PDF.
- Replace placeholder contact/navigation behavior when integrating into the team's main app.
